## What GiliSoft Exe Lock Does

GiliSoft Exe Lock is a Windows desktop utility that lets you decide how selected executable files may be opened and used. Instead of leaving applications freely available, you can require a password, apply a schedule, or impose network-related access conditions.

The program is suited to workflows that require controlled application launching across EXE, MSI, and BAT files. Its logging and usage-monitoring functions also provide a way to review access activity over time.

---

## Core Capabilities

- Restrict unrestricted launching of EXE, MSI, and BAT files
- Require passwords before protected programs can be opened
- Define scheduled availability through time-lock rules
- Capture usage events through logging and analytics
- Apply restrictions based on network or IP conditions
- Use protection workflows related to file encryption
- Select from a multi-language user interface
- Run on Windows desktop systems

## Operating the Application

Begin by choosing the file you want to manage, then assign the access conditions appropriate for your use case.

A standard setup looks like this:

1. Start GiliSoft Exe Lock.
2. Import the EXE, MSI, or BAT file that should be protected.
3. Turn on the password requirement for launching it.
4. Specify time limits or permitted usage periods.
5. Add IP or network conditions if required.
6. Save the rules and verify that the protected file behaves as expected.

When logging is active, check the recorded activity from time to time to identify when protected files were opened and which conditions applied.
